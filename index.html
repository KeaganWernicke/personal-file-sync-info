Personal File Sync

Personal File Sync is a personal utility for transferring selected personal files between its owner's devices using the owner's Google Drive. It is not offered as a public service.

The utility uses rclone to transfer selected files and maintain backups. Google authorization is performed in Google's sign-in flow. The utility does not request or store a Google account password.

Only the owner should authorize this application. There is no public registration or hosted file-storage service.
